# OLA Ride Data Analysis 🚖📊

## 📌 Project Overview
This project analyzes OLA ride booking data using SQL and Excel.  
The objective is to identify ride demand trends, revenue patterns, cancellation behavior, and customer segmentation.

---

## 🛠 Tools & Technologies Used
- MySQL
- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Data Visualization

---

## 📊 Key Analysis Performed

1. Total Revenue Analysis  
2. Ride Status Analysis (Completed / Cancelled)  
3. Customer Type Analysis (Registered vs Casual)  
4. Peak Booking Time Analysis  
5. Cancellation Rate Analysis  

---

## 📈 Dashboard Insights
- Registered users generate higher revenue.
- Most rides are booked during peak hours.
- Cancellation rate impacts total revenue significantly.

---

## 📂 Project Structure
- OLA dataset (CSV files)
- SQL Queries
- Excel Dashboard
- Screenshots of Analysis

---

## 🚀 Conclusion
The project provides business insights that can help improve ride efficiency, reduce cancellations, and increase overall revenue.
